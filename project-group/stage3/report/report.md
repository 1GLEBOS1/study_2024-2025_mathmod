# Выполнение лабораторной работы

Процесс теплопереноса в горящих средах представляет собой сложную нелинейную задачу, для которой требуется точное численное моделирование. В данной работе рассматривается однородная среда с источником тепла, моделирующим химическую реакцию.

В основе лежит уравнение теплопроводности с источником тепла, заданным в виде аррениусовской функции, что добавляет системе высокой нелинейности. Модель включает температурную зависимость теплопроводности и теплоемкости, что требует применения итерационных численных методов и адаптивных подходов к пространственной дискретизации.

## Математическая модель

Основное уравнение:

$$
\rho c \frac{\partial T}{\partial t} = \frac{\partial}{\partial x}\left(k \frac{\partial T}{\partial x}\right) + Q(T)
$$

где:

* $T(x,t)$ — температура,
* $k$ — коэффициент теплопроводности,
* $\rho$ — плотность,
* $c$ — удельная теплоемкость,
* $Q(T)$ — функция тепловыделения, моделирующая горение.

| Параметр | Описание | Пример значения |
|--------------|------------------|------------|
|L	 | Толщина пластины (м) | 	0.2 |

Функция источника задается в виде:

$$
Q(T) = A e^{-\frac{E}{RT}}
$$

где $A$, $E$, $R$ — параметры, определяющие интенсивность химической реакции.

## Численная схема

Для численного решения используется метод конечных разностей. Пространственная область дискретизуется с шагом $h$, временная — с шагом $\tau$.

Применена неявная схема (метод Кранка-Николсона) для повышения устойчивости при решении задачи с жесткими условиями. Уравнение аппроксимируется в виде:

$$
\frac{T_i^{n+1} - T_i^n}{\tau} = \frac{1}{2h^2} \left[ k_{i+1/2}(T_{i+1}^{n+1} - T_i^{n+1}) - k_{i-1/2}(T_i^{n+1} - T_{i-1}^{n+1}) + \text{аналогично для } n \right] + Q(T_i^{n+1})
$$

Для решения нелинейной системы на каждом шаге используется метод простых итераций с релаксацией. Критерий остановки: достижение заданной точности по норме разности температур между итерациями.

## Реализация и результаты

Задача реализована в виде программного кода (Julia, Python). Приведены графики распределения температуры во времени, демонстрирующие распространение тепловой волны и формирование фронта горения. Проводился расчет на нескольких пространственных разрешениях (число узлов $N=20$, $40$, $80$) с анализом устойчивости и точности.

Результаты демонстрируют:

* влияние шага по пространству и времени на точность решения;
* усиление нелинейности при увеличении параметра $A$ (интенсивность источника);
* необходимость адаптации сетки вблизи фронта для более точного разрешения.

# Выводы

* Использование неявной схемы обеспечивает устойчивость при решении задачи с жесткими источниками тепла.
* При больших значениях параметров горения требуется более тонкая пространственная сетка или использование адаптивных методов (например, подвижных сеток).
* Метод конечных разностей может быть успешно применен для одномерных задач, но требует модернизации при переходе к более сложным геометриям.
* Предложенная модель и схема адекватно описывают процесс распространения тепла и реакции, но требуют точной калибровки параметров модели.
